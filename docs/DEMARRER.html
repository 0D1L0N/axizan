Démarrer l’application, avec ou sans internet

Tout tient dans Docker. Une commande lance les sept services, et le projet reste entièrement utilisable hors connexion — à quelques détails près, listés plus bas.

01

Lancer l’application

Depuis le dossier du projet. Docker Desktop doit tourner.

PS> cd C:\Users\B4DM4N\source\repos\axizan PS> docker compose up -d

Sept services démarrent : postgres, redis, laravel, queue, scheduler, nextjs et mailpit.

Patience

Le front met une à deux minutes avant de répondre : Next.js recompile au premier démarrage. docker compose ps affichera « Up » bien avant que la page ne s’ouvre — c’est normal, laissez-le finir.

Pour vérifier que tout est debout :

PS> docker compose ps NAME STATUS axizan-laravel Up axizan-mailpit Up (healthy) axizan-nextjs Up axizan-postgres Up (healthy) axizan-queue Up axizan-redis Up (healthy) axizan-scheduler Up

Multi-rôles

Pour être connecté à plusieurs rôles en même temps, il faut des profils de navigateur séparés — le jeton vit dans le localStorage, partagé par tous les onglets d’un même site. Le mode privé ne suffit pas : toutes ses fenêtres partagent une session.

03

Ouvrir au public (avec internet)

Cloudflared crée une adresse publique temporaire pointant sur votre machine. Il n’est pas dans le PATH — donnez le chemin complet.

PS> & "C:\Program Files (x86)\cloudflared\cloudflared.exe" tunnel --url http://localhost:3000 Your quick Tunnel has been created! Visit it at: https://xxxx-xxxx-xxxx.trycloudflare.com

Une seule adresse suffit pour le site et l’API : les appels sont réécrits en interne vers le conteneur Laravel. Laissez la fenêtre ouverte — la fermer coupe le tunnel. Ctrl+C l’arrête proprement ; sinon Get-Process cloudflared | Stop-Process.

Attention

Quiconque a l’adresse peut se connecter en admin@test.com avec le mot de passe de démonstration, et valider des paiements. Ne partagez ce lien qu’à des gens de confiance, et fermez le tunnel après. L’adresse change à chaque redémarrage.

04

Sans connexion internet

L’essentiel fonctionne : les images Docker, les 463 paquets npm, les dépendances PHP et les polices sont déjà sur votre disque. Voici ce qui change réellement.

Ce que vous faitesHors lignePourquoi

Modifier le code fonctionne Le rechargement à chaud est local.

Tunnel public indisponible Par définition.
Le piège

Ne supprimez ni .next ni les volumes Docker pendant que vous êtes hors ligne. Les polices Fraunces et Plus Jakarta Sans sont téléchargées à la construction puis mises en cache dans .next. Purgé sans réseau, le projet ne se reconstruit plus. Même chose pour node_modules et vendor : les recréer demande npm install et composer install.

Si vous prévoyez de longues périodes hors ligne, je peux rapatrier les polices dans le dépôt (next/font/local) et remplacer les photos Unsplash par des fichiers locaux. Le projet deviendrait alors totalement autonome.

05

Quand ça coince

SymptômeCause et remède
Le site ne répond pas Next compile encore. docker compose logs nextjs --tail=20 — attendez la ligne ✓ Ready.
Erreur MODULE_NOT_FOUND Un npm run build a laissé une construction de production que le mode développement ne sait pas relire. Recréez le conteneur : docker compose rm -svf nextjs puis docker compose up -d nextjs.
L’API renvoie 500 Souvent le lien de stockage manquant après un clone : docker compose exec laravel php artisan storage:link.
Tout est Exited (255) Docker Desktop a redémarré. docker compose up -d suffit, les données sont intactes.
Erreur 429 à la connexion Le garde-fou anti force brute : 10 tentatives par minute. Attendez une minute.

Pour repartir d’une base propre — efface toutes les commandes :

PS> docker compose exec laravel php artisan migrate:fresh --seed
06

Commandes utiles

# Lancer la suite de tests PS> docker compose exec laravel ./vendor/bin/phpunit # Suivre les journaux du serveur PS> docker compose logs laravel -f # Voir les SMS (aucun agrégateur branché : ils s'écrivent dans le journal) PS> docker compose logs laravel | Select-String "SMS" # Tout arrêter, sans rien perdre PS> docker compose stop
Jamais

docker compose down -v supprime les volumes, donc la base de données. stop suffit pour éteindre.

Le suivi d’avancement du projet vit dans CHANTIERS.md, à la racine du dépôt. Les décisions produit et les points restés ouverts y sont datés.
